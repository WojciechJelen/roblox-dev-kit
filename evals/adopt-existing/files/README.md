# Motor Rivals

Car battles for up to 8 players. The scripts live in this folder and are pasted into Studio by
hand after every change.

## Where each script lives in Studio

| File | Studio location | Type |
|---|---|---|
| `src/Factory.lua` | `ReplicatedStorage.RivalsFactory` | ModuleScript |
| `src/FX.lua` | `ReplicatedStorage.RivalsFX` | ModuleScript |
| `src/Server.server.lua` | `ServerScriptService.RivalsServer` | Script |
| `src/Client.client.lua` | `StarterPlayer.StarterPlayerScripts.RivalsClient` | LocalScript |

The map, the cars and the UI are built in Studio and are not in this folder.
