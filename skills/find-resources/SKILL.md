# Find resources

`SKILL_DIR` is the directory that contains this SKILL.md: your harness shows it when the skill loads
(Oh My Pi appends `[Skill directory: <path>]`, and `skill://find-resources` resolves to it in bash).
Run scripts by absolute path. Every script has `--help`.

| Script | Does |
|---|---|
| `"$SKILL_DIR/scripts/search.sh" QUERY --type T` | searches the sources with an API, prints results with license, size facts and links, then browse links |
| `"$SKILL_DIR/scripts/fetch.sh" SOURCE:ID` | downloads a Poly Haven or ambientCG texture set (or an ambientCG model) with `SOURCE.json` and a credit |
| `"$SKILL_DIR/scripts/credit.sh" --name N --source URL --license L` | adds one row to the project's `CREDITS.md` (idempotent) |
| `"$SKILL_DIR/scripts/scan-model.sh" FILE` | lists a model's scripts and flags backdoor patterns (exit 0 clean, 1 findings) |

References: [sources.md](references/sources.md) (every source, how to search it, its license and
API), [licenses.md](references/licenses.md) (what each license allows in a Roblox game, credit
formats), [safety.md](references/safety.md) (backdoor patterns, the review checklist, false
positives).

## 1. Build or find

Look for a free asset first when the thing is laborious or looks poor when built from parts or
generated by code. Build it when it is simple geometry or specific to this game.

| Asked for | Default | Where to look first |
|---|---|---|
| Trees, rocks, bushes, grass, other foliage | find | Creator Store, Kenney (Nature Kit), KayKit, Quaternius, Poly Pizza |
| Vehicles, characters, creatures, weapons | find | Creator Store, Kenney, KayKit, Quaternius, Sketchfab |
| Furniture, detailed props, building kits | find | Kenney, KayKit, Creator Store |
| Realistic surfaces (brick, wood, metal, ground) | Roblox's built-in materials first, then find PBR | Poly Haven, ambientCG |
| Sound effects, music | find | Creator Store audio (section 2) |
| Icon sets, controller and keyboard glyphs | find | Kenney UI and Input Prompts, game-icons.net, Lucide, Phosphor, Material Symbols |
| Fonts | find | Creator Store fonts only (Roblox has no font upload) |
| Character animations | find | Roblox's own animations; Mixamo needs retargeting to R15 |
| Skies | find | Creator Store skyboxes (HDRIs do not work as Roblox skies) |
| Platforms, walls, obby parts, blockouts, terrain shapes | build | Parts, unions and Terrain are the right tool |
| UI layout, game logic, anything unique to this game | build | it is the game |

**Propose before building.** When the table says find, search (sections 2 and 3) and offer the
user two to four candidates, each with its source, license, size facts (triangles against the
20,000-per-mesh cap, texture resolution, duration) and what importing takes. Build from primitives
only when the user prefers that or nothing fits, and say which. Never invent asset ids, URLs or
licenses: use only what a search returned, and say when a search found nothing.

## 2. Roblox first

Creator Store assets are already in Roblox's formats and need no upload. Every Studio MCP tool
call (`search_asset`, `insert_asset`, `script_grep`, `script_read`, ...) takes a `studio_id`: get it
from `list_roblox_studios` first, and ask the user which Studio to use when several are open.

- **With Studio connected** (the Studio MCP tools are available), use `search_asset` with
  `scope: "creator_store"`, `priceFilter: "free"`, `verifiedCreatorsOnly: true`, the matching
  `assetType` (`Model`, `Audio`, `Mesh`, `MeshPart`, `Image`, `Decal`, `Video`, `Package`; most
  uploaded textures are `Image`) and `maxResults` up to 20; audio also takes
  `audioMinDuration`/`audioMaxDuration`. Results carry name, type, price, creator and a
  `thumbnailUrl`: fetch it to look at candidates before choosing.
- **Insert** with `insert_asset` (`assetId`, `assetName`, `assetType`) into a `Workspace` folder named
  after the source, for example `parentPath: "game.Workspace.CreatorStore"` (create the Folder first
  if it is missing), so third-party content stays easy to review and remove. Then check its
  scripts (section 5) before any play-test.
- **Without Studio**, `search.sh` asks the Creator Store's toolbox API (undocumented, may change),
  keeps free items only, and prints each asset's page, triangle count, duration and whether it has
  scripts. Insert later from Studio's Toolbox or with `insert_asset`.
- **Audio comes from the Creator Store library** whenever it has something fitting: Roblox's
  partners provide more than 100,000 sound effects and tracks that are free in experiences, while
  own uploads are capped (under 20 MB and 7 minutes, 100 per 30 days for unverified accounts,
  2,000 when ID-verified) and private until shared.
- Fonts install from the Toolbox into the font library; there is no other way to add one.

## 3. Search the free sources

```sh
"$SKILL_DIR/scripts/search.sh" "low poly pine tree" --type model
"$SKILL_DIR/scripts/search.sh" "mossy rock" --type texture --license cc0 --json
"$SKILL_DIR/scripts/search.sh" "door creak" --type sound --dry-run
```

- `--type` model, texture, hdri, sound, music, image, icon or all; `--source` a comma list of
  roblox, polyhaven, ambientcg, sketchfab, polypizza, freesound, pixabay; `--limit` per source
  (default 5); `--json` for your own parsing; `--dry-run` shows the requests; `--no-manual` drops
  the browse links.
- Freesound, Pixabay and Poly Pizza run only when `FREESOUND_API_KEY`, `PIXABAY_API_KEY` or
  `POLY_PIZZA_API_KEY` is set; otherwise one line says how to get a free key. Never ask the user to
  paste a key into the chat; they set it in their environment. Keys never appear on a command line
  or in output.
- A source that fails is a warning; exit 1 only when no source answered. The browse links
  (Kenney, KayKit, Quaternius, itch.io, OpenGameArt, Unsplash, Pixabay audio, icon sets) are still
  printed: open them in a browser if one is available, or give them to the user.
- **Whenever you show Poly Haven results, include the line "Powered by Poly Haven"** (its API
  terms; the script prints it under its rows and in `credits` in the JSON).
- Read the facts against Roblox's limits: Poly Haven models are dense photoscans (often millions of
  polys); Sketchfab results are capped at 20,000 faces by the search; textures above 1024 px need
  scaling down for PBR maps.

## 4. License gate

Check the license on the asset's own page before using it; the search result is a hint.
Details and credit formats: [licenses.md](references/licenses.md).

- **CC0** is preferred: no conditions.
- **CC-BY** (and OGA-BY): use it only with a credit: title, author, source and license, in
  `CREDITS.md` and on an in-game credits screen.
- **No NC** (non-commercial) in a game that earns Robux, which is nearly every game.
- **Avoid SA and ND** (share-alike, no-derivatives) and anything without a clear license.
- Special terms: Quaternius QAL (games yes, redistribution no), Fab Standard License (read it;
  legacy Quixel assets are not allowed), Pixabay and Unsplash licenses (free, no credit, no
  standalone resale), Mixamo (no redistribution of raw files), Creator Store (Roblox's terms).
- Record every third-party asset, CC0 included:
  `"$SKILL_DIR/scripts/credit.sh" --name "Pine Tree" --author "Jane Doe" --license "CC-BY 4.0" --source <page URL>`.
  `fetch.sh` does this itself. Write the version (`CC-BY 3.0` or `4.0`) and mark changed CC-BY 4.0
  assets "(modified)".
- Never upload a third-party asset to the Creator Store as a distributed asset of the user's own.

## 5. Safety: scan before use

Free models can carry backdoors: `require(<asset id>)` loaders, `loadstring`, `getfenv`, web
requests, hidden purchase prompts. Patterns, false positives and the checklist:
[safety.md](references/safety.md).

- **Every community model is scanned before it is used or play-tested** (a play-test runs its
  scripts): `"$SKILL_DIR/scripts/scan-model.sh" FreeTree.rbxmx` (`--json` for parsing). Report the
  verdict, each high finding with script and line, then the medium ones.
- **A model already in Studio**: grep for the same patterns with the Studio MCP `script_grep` (it
  searches every script in the place, so keep the matches inside the model) and read each of the
  model's scripts with `script_read`; or save the model to a file and run the scanner.
- **Delete scripts the model does not need** (a tree or a car body needs none), and do not use a
  model whose scripts you cannot read. Never enable `HttpEnabled` or `LoadStringEnabled` because a
  model asks for it. A clean scan is not proof: read what you keep.
- The scanner needs Lune from the toolchain (`~/.rokit/bin/lune`); without it, exit 2 says so:
  install the toolchain with the roblox-setup skill, or read the scripts in Studio instead.

## 6. Bring it into the game

- **3D files** (FBX, OBJ, glTF/GLB): check and convert with the **blender-to-roblox** skill
  (`check_mesh.py` against the 20,000-triangle cap per mesh, `export_fbx.py`, then Studio's 3D
  Importer or `upload-asset.sh`). A dense mesh is decimated or split into several meshes in Blender,
  never imported as is. Studio's Importer reads `.fbx`, `.obj` and `.gltf`/`.glb` directly for a
  quick first look.
- **Texture sets**: `"$SKILL_DIR/scripts/fetch.sh" polyhaven:<id>` or `ambientcg:<id>` (1k by
  default) puts the color, OpenGL normal, roughness and metalness maps in
  `assets/third-party/<source>/<id>/` with `SOURCE.json`. Roblox only reads OpenGL-style normal
  maps, which is why those are fetched. A Poly Haven set without a `Metal` map is not metallic
  (even under the "metal" category: painted or rusty metal), so leave `MetalnessMap` empty;
  `fetch.sh` still downloads its packed `arm` map and prints how to check the metalness channel
  (ImageMagick `magick <arm> -channel B -separate <metal>.png`, or Blender's Separate Color node). Upload each map (Asphalt, or
  `"$SKILL_DIR/../blender-to-roblox/scripts/upload-asset.sh" FILE --name N --type Image`; in Oh My
  Pi `skill://blender-to-roblox/scripts/upload-asset.sh`), then
  set `ColorMap`, `NormalMap`, `RoughnessMap` and `MetalnessMap` on a `SurfaceAppearance` under
  the MeshPart, or on a `MaterialVariant` in `MaterialService` for Parts and Terrain (with
  `StudsPerTile`). Each PBR map is at most 1024×1024. Put the asset ids in a Luau module in the
  Rojo project, not in scripts.
- **Icons**: Roblox has no SVG. Download PNG where the site offers it (Kenney, game-icons.net,
  Material Symbols) or rasterise the SVG at the size the UI shows it, then upload as an Image.
- **Fonts**: Creator Store fonts only.
- **Animations**: Roblox's own R15 animations first. Mixamo rigs are not R15; retargeting through
  Blender is real work, so say so before starting.
- **Other downloads** (Kenney, KayKit, Quaternius, Sketchfab, Freesound): download by hand (Sketchfab
  and Freesound need a login), keep the files under `assets/third-party/<source>/`, and run
  `credit.sh`. `fetch.sh sketchfab:<uid>` and the like print the steps.

Related skills: **blender-to-roblox** checks, fixes, exports and uploads the 3D files found here;
**roblox-setup** installs the toolchain (Lune for the scanner, Asphalt for uploads) and writes the
project's `AGENTS.md`, whose "find before you build" rule points to this skill.
